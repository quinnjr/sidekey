# SideKey Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Android app that holds `WRITE_SECURE_SETTINGS` and keeps `power_button_long_press` pinned to the user's chosen value, restoring the side-key long-press power menu on Samsung One UI 8+.

**Architecture:** All decision logic lives in pure Kotlin classes behind a `GlobalSettingsPort` interface, so it is unit-testable on the JVM with no device and no Robolectric. Android-specific classes (`PinService`, `BootReceiver`, Compose UI) are thin shells over that logic. The boot race is handled by a `ContentObserver` that re-asserts the value when the system rewrites it, rather than by writing on a guessed delay.

**Tech Stack:** Kotlin 2.4.10, AGP 9.3.1, Gradle 9.6.1, Compose BOM 2026.06.01, Shizuku API 13.1.5, JUnit 5, JDK 17.

## Global Constraints

- Package: `io.github.quinnjr.sidekey`
- `minSdk = 30` (Wireless debugging requires Android 11+), `compileSdk = 37`, `targetSdk = 36`
- JDK 17 toolchain; `_JAVA_OPTIONS` is set in this environment and prints a banner — harmless
- Gradle wrapper pinned to `9.6.1`

### Toolchain constraints discovered while building

These were found the hard way; do not "simplify" them back:

- **AGP must be 9.x.** Current AndroidX (`androidx.core:core:1.19.0`, `lifecycle:2.11.0`)
  requires `compileSdk 37` and AGP 9.1+. AGP 8.13.2 additionally fails on Gradle 9.6.x with
  `Plugin 'com.android.internal.application' relies on ... InternalProblems, removed in
  Gradle 9.6.0`.
- **Do not apply `org.jetbrains.kotlin.android`.** AGP 9 has built-in Kotlin and fails hard
  with "The 'org.jetbrains.kotlin.android' plugin is no longer required for Kotlin support
  since AGP 9.0." Only `org.jetbrains.kotlin.plugin.compose` is applied.
- **`platforms;android-37.0`** must be installed — note the `.0` suffix in the package name.
- **JUnit 5 needs `testRuntimeOnly(junit-platform-launcher)`**, else the run dies with
  "Failed to load JUnit Platform."
- **Shizuku must be `implementation`, not `compileOnly`** — `ShizukuEnv` touches it at
  runtime during bootstrap.
- Settings keys, verbatim: `power_button_long_press` (Global, int), `function_key_config_longpress_selected_item` (Global, string)
- `BuildConfig.REPORT_REPO` defaults to `"quinnjr/sidekey"`
- No backend, no analytics, no telemetry. Device reports go to GitHub or nowhere
- Never collect: serial, IMEI, `ANDROID_ID`, accounts, installed apps, location, free text
- Every write returns a typed result; silent failure is forbidden
- Reference: `docs/superpowers/specs/2026-07-27-sidekey-design.md`

```kotlin
const val KEY_PBLP = "power_button_long_press"
const val KEY_FUNCTION_LONGPRESS = "function_key_config_longpress_selected_item"

sealed class Behavior(val pblp: Int, val functionKeyItem: String?) {
    data object PowerMenu : Behavior(1, "long_press_power_off")
    data object Assistant : Behavior(5, null)
    data object Nothing : Behavior(0, null)
    data object SamsungAi : Behavior(101, null)
    data class Raw(val value: Int) : Behavior(value, null)

    companion object {
        fun fromInt(value: Int): Behavior = when (value) {
            1 -> PowerMenu
            5 -> Assistant
            0 -> Nothing
            101 -> SamsungAi
            else -> Raw(value)
        }
    }
}
```

```kotlin
package io.github.quinnjr.sidekey.core

class KeyBehaviorRepo(private val settings: GlobalSettingsPort) {

    fun observed(): Behavior? = settings.getInt(KEY_PBLP)?.let(Behavior::fromInt)

    fun apply(behavior: Behavior): WriteResult {
        val result = settings.putInt(KEY_PBLP, behavior.pblp)
        if (result != WriteResult.Ok) return result
        behavior.functionKeyItem?.let { settings.putString(KEY_FUNCTION_LONGPRESS, it) }
        val readBack = settings.getInt(KEY_PBLP)
        return if (readBack == behavior.pblp) WriteResult.Ok
        else WriteResult.Overridden(readBack ?: -1)
    }
}
```

### Task 4: `PinPolicy` — the boot-race state machine

**Files:**

**Interfaces:**
- Produces: `PinPolicy(desired: Int, stabilityWindowMs: Long = 60_000)` with `decide(observed: Int?, elapsedMs: Long): PinDecision`; `PinDecision` = `Write` | `Idle` | `Stop`

This is the class that answers the measured 3.7 s boot race. `Stop` only after the value
has been correct for the whole window, so a late system write is still caught.

```kotlin
package io.github.quinnjr.sidekey.core

sealed interface PinDecision {
    data object Write : PinDecision
    data object Idle : PinDecision
    data object Stop : PinDecision
}

class PinPolicy(private val desired: Int, private val stabilityWindowMs: Long = 60_000) {
    fun decide(observed: Int?, elapsedMs: Long): PinDecision = when {
        observed != desired -> PinDecision.Write
        elapsedMs >= stabilityWindowMs -> PinDecision.Stop
        else -> PinDecision.Idle
    }
}
```

- [ ] **Step 4: Implement `IssueUrlBuilder`**

`java.net.URLEncoder` encodes a space as `+`, which is correct for a query string and
what GitHub expects. It leaves `*` unencoded and encodes `~`; neither appears in the
payload, so no post-processing is needed.

```kotlin
package io.github.quinnjr.sidekey.report

import java.net.URLEncoder

sealed interface IssueUrl {
    data class Ready(val uri: String) : IssueUrl
    data class TooLong(val blankIssueUri: String, val body: String) : IssueUrl
}

object IssueUrlBuilder {
    const val MAX_URL_LENGTH = 6000
    private const val LABEL = "device-report"

    fun build(repo: String, report: DeviceReport): IssueUrl {
        val base = "https://github.com/$repo/issues/new"
        val body = report.toMarkdown()
        val uri = base +
            "?labels=" + enc(LABEL) +
            "&title=" + enc(report.title()) +
            "&body=" + enc(body)
        return if (uri.length <= MAX_URL_LENGTH) IssueUrl.Ready(uri)
        else IssueUrl.TooLong(base, body)
    }

    private fun enc(s: String): String = URLEncoder.encode(s, "UTF-8")
}
```

```kotlin
package io.github.quinnjr.sidekey.core

import android.content.Context
import android.provider.Settings

class AndroidGlobalSettings(context: Context) : GlobalSettingsPort {
    private val resolver = context.contentResolver

    override fun getInt(key: String): Int? =
        try { Settings.Global.getInt(resolver, key) }
        catch (_: Settings.SettingNotFoundException) { null }

    override fun getString(key: String): String? = Settings.Global.getString(resolver, key)

    override fun putInt(key: String, value: Int): WriteResult = guard {
        if (Settings.Global.putInt(resolver, key, value)) WriteResult.Ok
        else WriteResult.Rejected("putInt returned false for $key")
    }

    override fun putString(key: String, value: String): WriteResult = guard {
        if (Settings.Global.putString(resolver, key, value)) WriteResult.Ok
        else WriteResult.Rejected("putString returned false for $key")
    }

    private inline fun guard(block: () -> WriteResult): WriteResult =
        try { block() }
        catch (_: SecurityException) { WriteResult.NoPermission }
        catch (e: Exception) { WriteResult.Rejected(e.message ?: e::class.java.simpleName) }
}
```

```kotlin
package io.github.quinnjr.sidekey.service

import android.app.Notification
import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.Service
import android.content.Context
import android.content.Intent
import android.database.ContentObserver
import android.os.Handler
import android.os.IBinder
import android.os.Looper
import android.os.SystemClock
import android.provider.Settings
import io.github.quinnjr.sidekey.core.*

class PinService : Service() {

    private val handler = Handler(Looper.getMainLooper())
    private lateinit var repo: KeyBehaviorRepo
    private lateinit var settings: GlobalSettingsPort
    private lateinit var policy: PinPolicy
    private var desired = 1
    private var startedAt = 0L
    private var observer: ContentObserver? = null

    override fun onBind(intent: Intent?): IBinder? = null

    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        desired = intent?.getIntExtra(EXTRA_DESIRED, 1) ?: 1
        settings = AndroidGlobalSettings(this)
        repo = KeyBehaviorRepo(settings)
        policy = PinPolicy(desired)
        startedAt = SystemClock.elapsedRealtime()

        startForeground(NOTIFICATION_ID, notification())
        registerObserver()
        evaluate()
        handler.postDelayed(::evaluate, STABILITY_MS)
        return START_STICKY
    }

    private fun registerObserver() {
        val o = object : ContentObserver(handler) {
            override fun onChange(selfChange: Boolean) = evaluate()
        }
        contentResolver.registerContentObserver(
            Settings.Global.getUriFor(KEY_PBLP), false, o
        )
        observer = o
    }

    private fun evaluate() {
        val elapsed = SystemClock.elapsedRealtime() - startedAt
        when (policy.decide(settings.getInt(KEY_PBLP), elapsed)) {
            PinDecision.Write -> repo.apply(Behavior.fromInt(desired))
            PinDecision.Idle -> Unit
            PinDecision.Stop -> stopSelf()
        }
    }

    override fun onDestroy() {
        observer?.let(contentResolver::unregisterContentObserver)
        handler.removeCallbacksAndMessages(null)
        super.onDestroy()
    }

    private fun notification(): Notification {
        val mgr = getSystemService(NotificationManager::class.java)
        mgr.createNotificationChannel(
            NotificationChannel(CHANNEL, "Pinning side key", NotificationManager.IMPORTANCE_MIN)
        )
        return Notification.Builder(this, CHANNEL)
            .setContentTitle("Restoring the side key power menu")
            .setSmallIcon(android.R.drawable.ic_lock_power_off)
            .build()
    }

    companion object {
        private const val CHANNEL = "pin"
        private const val NOTIFICATION_ID = 1
        private const val STABILITY_MS = 60_000L
        const val EXTRA_DESIRED = "desired"

        fun start(context: Context, desired: Int) {
            val intent = Intent(context, PinService::class.java)
                .putExtra(EXTRA_DESIRED, desired)
            context.startForegroundService(intent)
        }
    }
}
```

```kotlin
package io.github.quinnjr.sidekey.bootstrap

sealed interface BootstrapState {
    data object Granted : BootstrapState
    data object ShizukuReady : BootstrapState
    data object ShizukuMissing : BootstrapState
    data object ShizukuDenied : BootstrapState
}

interface BootstrapEnv {
    fun hasPermission(): Boolean
    fun shizukuAvailable(): Boolean
    fun shizukuGranted(): Boolean
    fun runShell(command: String): Int
}

class Bootstrapper(
    private val env: BootstrapEnv,
    private val packageName: String = "io.github.quinnjr.sidekey",
) {
    fun state(): BootstrapState = when {
        env.hasPermission() -> BootstrapState.Granted
        !env.shizukuAvailable() -> BootstrapState.ShizukuMissing
        !env.shizukuGranted() -> BootstrapState.ShizukuDenied
        else -> BootstrapState.ShizukuReady
    }

    fun selfGrant(): Boolean =
        env.runShell("pm grant $packageName android.permission.WRITE_SECURE_SETTINGS") == 0
}
```

```kotlin
package io.github.quinnjr.sidekey.bootstrap

import android.content.Context
import android.content.pm.PackageManager
import rikka.shizuku.Shizuku
import rikka.shizuku.ShizukuBinderWrapper
import android.os.Build

class ShizukuEnv(private val context: Context) : BootstrapEnv {

    override fun hasPermission(): Boolean =
        context.checkSelfPermission(android.Manifest.permission.WRITE_SECURE_SETTINGS) ==
            PackageManager.PERMISSION_GRANTED

    override fun shizukuAvailable(): Boolean =
        runCatching { Shizuku.pingBinder() }.getOrDefault(false)

    override fun shizukuGranted(): Boolean =
        runCatching { Shizuku.checkSelfPermission() == PackageManager.PERMISSION_GRANTED }
            .getOrDefault(false)

    override fun runShell(command: String): Int = runCatching {
        val process = Shizuku.newProcess(arrayOf("sh", "-c", command), null, null)
        process.waitFor()
    }.getOrDefault(-1)
}
```

`Shizuku.newProcess` is annotated `@hide` in the Shizuku API but is the supported path for
shell execution; it is wrapped in `runCatching` so an API change degrades to a failed grant
with a visible error rather than a crash.
